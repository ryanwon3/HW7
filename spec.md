# Game Spec

## The game

You control a small character which you move around by right clicking on the screen. Meanwhile, projectiles will come at you from all directions and you must move to dodge them. At the same time, there is a rhythm game where using your left hand you must press qwer to falling keys like piano tiles. Surviving longer with over 80% accuracy gives you points.

## Intended features

Ability to upload any youtube / spotify link and automatically create a piano tiles map for you to play the game through. Ability for character to move. Different projectiles to dodge.

## Acceptance criteria

The player can move by right clicking on the screen. Accuracy on the rhythm game is tracked and accurate. The projectiles have accurate hitboxes.

## Priorities

Player movement, projectiles, basic rhythm game logic.
